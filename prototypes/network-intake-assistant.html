Proyecto

Ubicaciones

Define sedes, edificios, plantas, salas o CPD. El alcance de cada VLAN podrá referenciar estas ubicaciones.

VLANs, subredes y alcance

Cada VLAN actúa como segmento lógico. Define función, red, gateway, DHCP, nivel de confianza y dónde debe existir.

Grupos de hosts

Un grupo representa hosts con la misma función y política. El prototipo expande la cantidad indicada a hosts individuales.

Comunicaciones y política firewall

Define quién inicia la comunicación, hacia qué zona/grupo, protocolo, puertos, acción, motivo y registro.

El prototipo usa default deny como diseño recomendado. Las reglas ALLOW deben describir necesidades concretas. Las reglas con ANY, destinos amplios o acceso desde Guest/IoT hacia Management generan advertencias.
