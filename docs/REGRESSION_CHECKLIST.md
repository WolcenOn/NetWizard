# Checklist de regresión manual

Probar después de cada refactor:

1. Cargar la app.
2. Crear/cambiar nombre de proyecto.
3. Añadir ubicación física.
4. Añadir dispositivo.
5. Editar dispositivo.
6. Generar 24 puertos en switch.
7. Añadir puerto manual.
8. Crear VLAN.
9. Crear subnet manual.
10. Ejecutar auto-subnetting.
11. Añadir host DHCP.
12. Añadir host con IP estática.
13. Asignar host a puerto.
14. Crear enlace entre puertos.
15. Crear regla firewall.
16. Aplicar plantilla firewall.
17. Usar matriz inter-VLAN.
18. Cambiar hardening.
19. Aplicar RoaS.
20. Revisar DHCP por VLAN.
21. Ver topología clásica.
22. Usar Vista Visual V5: auto-ubicar, mover nodos, fullscreen.
23. Generar configuración por dispositivo.
24. Exportar JSON.
25. Importar JSON.
26. Recargar navegador y verificar persistencia.
