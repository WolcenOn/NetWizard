# NetWizard v3.48 · Release notes

## Cambios

- Sistema i18n ampliable con `i18n/locales.json`.
- Scripts para validar, sincronizar y crear idiomas.
- Selector UI/informes preparado para más de dos idiomas.
- API i18n ampliada con `registerLocale`, `loadExternalLocale` y `getLocaleMeta`.
- Tests para registro dinámico de idiomas y manifiesto.
- Auditor de textos hardcoded para guiar la traducción completa.

## Sin cambios destructivos

- No se traducen claves internas del JSON.
- No cambia el schema funcional del proyecto.
- No se añaden funciones de red nuevas.
