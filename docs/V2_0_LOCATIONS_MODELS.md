# NetWizard v2.0 · Ubicaciones y catálogo de modelos

## Cambios

- Se corrige la sincronización entre ubicaciones físicas y ubicaciones visuales V5.
- Las ubicaciones creadas o existentes en V5 aparecen también en el listado de ubicaciones.
- Las ubicaciones físicas se reflejan en V5 para que no existan dos modelos separados.
- Se añade un catálogo inicial de modelos/capacidades para dispositivos.
- Se añade campo Modelo / plantilla de capacidades en Dispositivos.
- Se añade campo Rol inalámbrico: sin Wi-Fi, AP, router Wi-Fi integrado o controlador WLAN.
- Se añade botón Aplicar capacidades del modelo.
- Al guardar un dispositivo con modelo conocido se generan puertos faltantes sin borrar puertos ya creados.

## Objetivo futuro

Preparar la asignación automática de hosts a puertos libres según:

1. ubicación física,
2. ubicación visual V5,
3. VLAN requerida,
4. tipo de host,
5. puertos disponibles,
6. capacidades del modelo,
7. si el dispositivo actúa como AP, switch, router o controlador inalámbrico.
